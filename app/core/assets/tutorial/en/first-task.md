Once connected, walk through these steps and you will have seen Relay's main flow.

## 1. Check the machine and agent

Tap the machine card on Home to open [Machine details](machine-details.md). Under **CLI agents**, confirm the one you want shows ready. If it is not logged in, sign in to that CLI on the backend host and select **Recheck**.

## 2. Pick the workspace

A new device starts in `~/Relay` on the backend (the deployment can change this). To use your project:

1. Tap **Current workspace** on Home, or **File system** at the bottom of the drawer.
2. Open the project directory.
3. Select **Set as work path**.

Merely browsing another folder does not switch the workspace. See [Workspaces](workspaces.md).

## 3. Pick an agent and session

Open the drawer (on a phone you can also swipe right anywhere in a chat) and tap an agent. Its sessions open below it, starting with Main. Use the **+** to the agent's right to create a session; see [Sessions](sessions.md).

The chat header shows the workspace, with "Agent - Session" below it. Glance at both before sending.

## 4. Set the model and permission

Tap the **+** left of the composer; the first row holds **Model**, **Effort**, **Permission** and so on. The defaults are fine to start; when the agent needs to edit files, make sure the permission allows edits. See [Model, effort, permission and Fast mode](agent-controls.md).

## 5. Send a simple task

For example:

> Explain the structure of this project

The reply appears as it is written, and you can select **Stop** at any time. Leaving the page does not interrupt the task; come back to see its progress.

## 6. Keep going

- Ask for a concrete change, then check the result in the [file browser](file-browser.md).
- Use a new session for a new task and the existing one for follow-ups.
- Find earlier results with [Search history and export](history-search.md).
