## Home

| Area | Does |
|---|---|
| Current machine | opens [Machine details](machine-details.md) |
| Current workspace | opens the [file browser](file-browser.md) |
| Recent workspaces | up to 5 directories with chat history; tap another one to switch to it |
| What's new | what this version adds |
| Tutorial | where you are now |

## The drawer

On wide screens it stays on the left; on a phone tap the menu button, or swipe right anywhere in a chat. From top to bottom:

1. **Machine card**: the connected machine and whether it is online.
2. **Quota usage**: opens [Quota usage](quota-usage.md), where Scheduled messages also live.
3. **Swarm**: shows a count; opens the Swarm list. See [Create a Swarm](swarm-basics.md).
4. **CLI agents**: the usable agents. The selected agent's sessions open below it; the **+** on its right creates a session; the status lights show install and login state. Unusable agents fold into one last row, "n unavailable". The refresh button next to the heading resyncs the session lists for the current workspace.
5. **Bottom row**: Home, Browser, File system, Settings.

## The chat screen

- **Title**: the workspace on top (tap it to open the file browser), "Agent - Session" below.
- **Search button**: searches history in the current workspace; see [Search history and export](history-search.md).
- **Quota strip**: above the composer, the current agent's remaining quota (Claude Code, Codex, Cursor).
- **Context usage**: for example `42k / 200k`; see [Context usage](context-usage.md).
- **+ left of the composer**: Model, Effort, Permission, Fast mode, Update CLI, plus Attach file, Clear chat, Compress and Export Markdown; see [Composer tools](composer-tools.md).

## Settings

Manage credentials, Appearance (theme, font size, wallpaper), Language, Notifications, Tutorial, and About (version and Check for updates). See [Theme, language and font size](appearance.md).
