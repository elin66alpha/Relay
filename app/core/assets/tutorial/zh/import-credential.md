凭证是 App 连接后端的钥匙。它是一个加密的 `relay.credentials.v1` 文件，里面有后端地址、机器标识和一个可以单独撤销的设备令牌。加密方式是 PBKDF2-HMAC-SHA256（60 万次迭代）加 AES-256-GCM。

## 导入方式

打开「设置」最上方的「管理凭证」，或者在还没有任何机器时的首屏：

| 方式 | 平台 |
|---|---|
| 扫描二维码 | Android、iOS |
| 上传二维码图片 | 所有平台 |
| 粘贴凭证（二维码内容或 `.relay.json` 的文字） | 所有平台 |

然后输入**生成凭证时设置的密码**，点「解密」。App 会立即测试连接。

## 常见提示

- **凭证解密失败**：密码不对，或者二维码不完整。
- **令牌被拒绝**：这份凭证的令牌已被撤销，或已被新生成的凭证替换。到后端重新生成并导入最新的一份。
- **无法解析地址**：二维码里的地址失效了。用 Cloudflare 快速隧道时，地址重启后会变。
- **端口拒绝连接**：后端没在运行，或者没有监听二维码里的端口。
- **使用明文 HTTP？**：地址是 `http://`。在可信的局域网里可以继续；经过互联网时请改用 HTTPS。

## 多台机器

每台后端各导入一份凭证即可。首页和侧边栏顶部的机器卡片显示当前连接的机器；在「管理凭证」里点另一台就能切换，也可以点「测试当前机器」检查连接，或删除不再使用的机器。

切换机器后，工作区、会话列表和蜂群都会换成那台机器上的。蜂群还可以把多台机器上的智能体拉到一起，见[其他机器上的成员](swarm-remote-members.md)。

## 在后端生成更多凭证

在后端的 `server/` 目录：

```bash
npm run credential
npm run credential -- --url https://relay.example.com
npm run credential -- --list-tokens
npm run credential -- --revoke <token-id>
```

Linux 和 macOS 的安装菜单、Windows 的 `Setup.exe` 也能创建、列出、删除令牌或重新显示二维码（重新显示会要求设置新密码，因为旧密码从不保存）。

## 凭证存在哪里

原生 App 保存在系统安全存储里。网页版保存在浏览器的站点存储中，安全性取决于浏览器，请只在可信设备上使用。

撤销和查看设备见[设备令牌](device-tokens.md)。
