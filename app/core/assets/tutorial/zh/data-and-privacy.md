Relay 没有云端，所有数据都在你的后端和设备上。

## 后端（`server/` 目录下）

| 数据 | 说明 |
|---|---|
| `.env` | 部署设置 |
| `tokens.json`、`credentials/` | 设备令牌和导出的凭证 |
| `chat-history.json` | 聊天记录，每个对话最近 200 条，**未加密** |
| 会话、设置、蜂群 | 命名会话、每个会话的设置、蜂群配置 |
| `agent-sessions.json` | 各 CLI 的对话恢复 ID |
| `context-windows.json`、`reported-models.json` | 上下文窗口大小、模型列表缓存 |
| `cursor-config/` | Relay 自己的 Cursor 配置 |
| 额度状态、定时消息、用量缓存 | |
| 推送订阅、FCM 设备 | |

另外，各 CLI 自己在主机上保存登录信息和对话记录，由它们自己管理。

这些都是**部署状态**，可能包含提示词、代码和账号信息。不要提交到 git，不要放进分享的压缩包，备份时和后端账号同等保护。

## 设备上

- 机器凭证：原生 App 在系统安全存储，网页版在浏览器站点存储。
- 每台机器的当前工作区、主题、语言、字体、通知开关。
- 壁纸图片（不上传）。

## 删除

删除会话会删除 Relay 的历史和恢复 ID，并请 CLI 删除它的对话记录；后者取决于 CLI，需要彻底清除时请检查主机上的 CLI 数据。卸载脚本会保留配置、令牌、凭证和历史，需要手动清理。
