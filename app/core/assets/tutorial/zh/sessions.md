在同一个工作区里，每个智能体最多可以有 **8 个命名会话**。每个会话是一段独立的对话，有自己的历史、设置和 CLI 侧上下文。

## 在哪里管理

在侧边栏选中一个智能体，它下方会展开会话列表：

| 操作 | 方法 |
|---|---|
| 新建 | 智能体右侧的 **+**，可以输入名称（不填则自动命名） |
| 切换 | 点会话名 |
| 重命名 | 会话名旁的编辑按钮 |
| 删除 | 会话名旁的删除按钮 |

正在运行的会话会有标记。如果会话列表还是上一个工作区的，点「CLI 智能体」标题旁的刷新按钮重新同步。

## Main 会话

Main 保留最初的对话，不能删除或重命名。

## 删除会话会怎样

删除会清除这个会话的聊天记录和机器侧上下文，**不会改动工作区里的文件**。Relay 也会请 CLI 删除它自己的对话记录，但这一步取决于 CLI 本身；需要彻底清除时，请到主机上检查 CLI 的数据。

## 跨设备共享

使用同一个工作区、同一个智能体、同一个会话的设备，共享历史和实时进度。你可以在电脑上发任务，在手机上看结果。

## 设置跟着会话走

模型、思考强度、权限和快速模式按会话保存。新建会话时复制当前会话的设置，之后互不影响。见[模型、思考强度、权限与快速模式](agent-controls.md)。

## 什么时候开新会话

新任务开新会话，追问用原会话。这样上下文更干净，也更省额度。同一个会话里的消息依次排队执行，不同会话可以同时运行。
