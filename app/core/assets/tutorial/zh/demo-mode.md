如果还没有部署 Relay 后端，可以先使用**演示模式**体验界面和交互，不需要服务器或网络连接。

## 进入演示模式

1. 在尚未导入任何机器凭证的初始欢迎页，点击**试用演示**。
2. Relay 会启用一台内置的模拟机器（`Relay Demo`）。聊天和后端响应都在本地模拟生成，演示期间会跳过自动检查更新和推送注册。

演示机器激活期间，界面顶部会显示**演示模式**横幅。

## 演示模式下可以使用什么

- **首页、侧边栏与单聊**：浏览首页工作区信息，打开 **Claude Code** 或 **Codex**，切换模型、思考深度和权限选项，并发送消息查看流式模拟回复。
- **机器详情与额度查询**：查看模拟的硬件参数和配额进度条。

由于没有真实的后端主机，**文件附件**、**SSH 终端**、**浏览器**、文件浏览和蜂群无法连接真实环境——**进入SSH** 和**浏览器**入口在演示模式下会被禁用，其他仅限后端的操作会提示演示模式下不可用。

## 退出演示模式

- 点击顶部**演示模式**横幅中的**退出演示**，即可删除演示机器并返回初始导入凭证页面。
- 也可以在**设置 → 机器凭证 → 添加机器**中导入真实机器凭证——导入真实机器时会自动移除演示机器。

准备好使用真实智能体时，可以参考[部署后端](deploy-backend.md)和[导入凭证与管理机器](import-credential.md)；如果需要现成的后端，也可以通过欢迎页或**设置 → 关于**中的 GitHub 链接联系作者。
