## 首页

| 区域 | 作用 |
|---|---|
| 当前机器 | 点它打开[机器详情](machine-details.md) |
| 当前工作区 | 点它打开[文件系统](file-browser.md) |
| 最近工作过的工作区 | 最多 5 个有聊天记录的目录；点其他目录直接切换过去 |
| 新功能 | 这个版本新增了什么 |
| 教程 | 就是你现在看的这里 |

## 侧边栏

在宽屏上固定在左侧；手机上点左上角菜单，或在聊天页任意位置向右滑打开。从上到下：

1. **机器卡片**：当前连接的机器，以及在线状态。
2. **额度查询**：打开[额度查询](quota-usage.md)，定时消息也在这里。
3. **蜂群**：显示数量，点进去是蜂群列表，见[创建蜂群](swarm-basics.md)。
4. **CLI 智能体**：可用的智能体。选中的智能体下方展开它的会话；右侧 **+** 新建会话；状态灯表示安装和登录情况。不可用的智能体收进末尾一行「另有 n 个不可用」。标题旁的刷新按钮会重新同步当前工作区的会话列表。
5. **底部一行**：首页、浏览器、文件系统、设置。

## 聊天页

- **标题**：上面一行是工作区，点它打开文件系统；下面一行是「智能体 - 会话」。
- **搜索按钮**：在当前工作区里搜索历史，见[搜索历史与导出](history-search.md)。
- **额度条**：输入框上方显示当前智能体的剩余额度（Claude Code、Codex、Cursor）。
- **上下文用量**：例如 `42k / 200k`，见[上下文用量](context-usage.md)。
- **输入框左侧的 +**：模型、思考、权限、快速模式、更新 CLI，以及附加文件、清空、压缩、导出 Markdown，见[输入框工具](composer-tools.md)。
