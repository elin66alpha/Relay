蜂群成员可以是**另一台 Relay 后端**上的智能体。蜂群本身、聊天记录和轮次都留在创建它的后端（A）上；轮到远程成员时，A 通过另一台后端（B）的普通 API 发送这一轮。B 不需要任何改动，版本也可以较旧。

## 要求

- 这台设备的「设置 → 机器凭证」里有 B 的凭证。
- App 每次请求都会附带 B 的凭证，A **不保存**它。

## 添加

在蜂群表单里，其他机器的智能体列在本机之后，标签带上机器名，例如 `Claude Code (Studio)`。当两个成员是同一种智能体时，本机成员也会带上本机主机名。召唤远程成员既可以用易读代号（如 `@studio:claude`），也可以用 `@<peerId>:claude` 或昵称。

添加时 A 会检查 B 能否访问、是否有这个智能体，然后在 B 上创建一个专用的隐藏蜂群会话（`Swarm: <蜂群名>`）。隐藏蜂群会话不会出现在 B 的侧边栏，不会变成 B 的活动会话，不占 B 的 8 会话上限，也不会出现在历史搜索里。如果 B 是旧版本，A 会在并发轮次结束后恢复 B 原来的活动会话。

远程成员只设置**昵称、提示词和 B 上的工作目录**（默认是 B 的默认目录）。以后可以通过「更改工作目录」修改，系统会在新目录建新会话并删除旧会话。模型、思考强度和权限沿用 B 上那个会话的设置。每个成员的提示词都会说明各成员所在的机器与目录，并提醒它不能直接读写其他机器上的文件。

## 没有 B 的凭证时

在没有 B 凭证的设备上，该成员显示「此设备未连接该机器」。召唤它时它这一轮会失败，其他成员照常运行。所以只有持有 B 凭证的设备才能召唤 B 的成员。

## 错误

| 情况 | 结果 |
|---|---|
| B 无法访问、凭证被拒、超时 | 该成员这一轮以错误结束 |
| 添加时 B 没有这个智能体 | 添加失败，不创建任何东西 |

## 停止、删除和清空

- 停止会用同一个请求 ID 取消 B 上的那一轮。
- 删除蜂群或移除成员时会删除 B 上的会话，清空蜂群时会清空它（请求带着 B 的凭证时）；这些都不会阻止 A 上的操作。

B 把这些轮次看作来自这台设备的普通轮次。如果没有设备在 B 上打开那个工作目录，B 会自己发送任务完成通知。

[Relay MCP](relay-mcp.md) 不能运行其他机器上的成员。
