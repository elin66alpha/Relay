点输入框左侧的 **+**，第一行是当前智能体支持的控制项。每一项打开一个选择页。

## 设置按会话保存

设置属于「工作区 + 智能体 + 会话」，所有使用这个会话的设备共享。新会话复制当前会话的设置，之后独立。

## 模型

选择页先列出主要模型；底部链接打开第二页：

- **旧版模型**（Claude Code、Codex）：较旧的版本，仍可选择。
- **需要支付方式的模型**（Cursor）：Cursor 套餐包含用量之外的模型（Auto、Grok、Composer 以外），从第一次请求起就扣预付费用量。

OpenCode 列出主机上 OpenCode 提供的模型，包括你在那里配置的 provider；Hermes 只显示主机上配置的那一个模型。可选模型由主机上的 CLI 决定，更新 CLI 后会刷新。

## 思考强度

从低到高可能有：无、极低、低、中、高、极高、最高、极限。具体有哪几档由智能体和模型决定，Codex、Cursor 和 Antigravity 的档位随模型变化。

## 权限

Relay 没有逐条审批的界面，所以权限档位决定了智能体遇到需要批准的操作时怎么办。

| 智能体 | 档位（第一个以外的含义） |
|---|---|
| Claude Code | 完全自动（跳过所有检查）、自动接受编辑（默认）、仅规划（只读） |
| Codex | 工作区可写（默认，网络和其他路径受限）、只读、完全访问（无沙箱） |
| Cursor | 完全自动（默认）、仅规划（只读）、只问答（只读） |
| OpenCode | 完全自动（默认）、询问（需要批准的操作被拒绝） |
| Hermes | 自动批准 yolo（默认）、谨慎（拒绝需批准的操作） |
| Antigravity | 谨慎（默认，拒绝需批准的请求）、自动批准 |

[隔离安装](file-access-mode.md)不提供「完全自动 / 完全访问 / 自动批准」这一档。

按任务选择：只想看看代码时用只读档，要改代码时用可编辑档。

## 快速模式

Claude Code、Codex 和 Cursor 支持快速模式，默认关闭。它以更高的用量或费用换取更快的响应，是否可用取决于模型、CLI 版本和账号。只在单聊里显示。

## 更新 CLI

同一行最后的「更新 CLI」会在后端主机上运行该 CLI 的自更新，可能需要一两分钟；完成后自动刷新可选的模型和思考档位。

## 设置何时生效

- Claude Code：改设置会重启它的进程并恢复同一对话。
- Codex：模型、思考、快速模式每轮生效；改沙箱会重新打开对话。
- Cursor：每种组合使用独立进程，切换时在对应进程里恢复对话。Relay 使用自己的 Cursor 配置目录，不会改动主机上 `~/.cursor` 的默认设置。
- OpenCode、Hermes：直接生效，不重启。

各智能体的细节见「智能体」分类，例如 [Claude Code](claude-code.md)。
