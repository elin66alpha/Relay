## 复制和编辑

每条已完成的消息都有：

- **复制**：复制到剪贴板。智能体的回复复制最终回答。
- **编辑**（只有你自己的消息）：把这条消息的文字放回输入框，修改后再发送。它不会改动已有的历史，也不会自动发送。

也可以直接长按或拖动选择消息里的文字。

## 回复里的链接

单聊里已完成的回复中，Markdown 链接可以点击：

| 链接 | 行为 |
|---|---|
| 文件路径（绝对路径，或相对于工作区） | 打开文件预览；是目录时打开文件系统 |
| 网址（`http`、`https`、`mailto`） | 先弹窗显示完整地址，确认后才用系统浏览器打开 |

文件路径后的 `:42` 或 `#L42` 行号会被忽略。访问文件同样受文件 API 的路径限制，见[文件访问：开放与隔离](file-access-mode.md)。

其他协议的链接不响应；不是 Markdown 链接的纯文本路径保持为文字；蜂群聊天里的链接不打开。
