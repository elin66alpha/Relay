单聊输入框上方显示当前对话的上下文用量，格式是 `已用 / 窗口`，单位是 token，例如 `42k / 200k`。

| 显示 | 含义 |
|---|---|
| `0 / 200k` | 新对话或刚清空 |
| `? / 200k` | 有回复，但智能体没有报告用量 |
| `42k / ?` | 这个智能体和模型还没有报告过窗口大小 |

数值来自对话里最近一次报告的用量。后端会记住每个智能体加模型最近报告的窗口大小，所以空对话也能显示上限。

Cursor 不报告上下文用量，选中 Cursor 时这一行隐藏。Antigravity 的用量从它的语言服务器读取。

上下文快满时，可以[压缩对话](composer-tools.md)或开一个新会话。
