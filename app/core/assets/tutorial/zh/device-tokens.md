每份凭证里有一个设备令牌，后端的每个 API 请求都需要它。每台设备（以及每个 [Relay MCP](relay-mcp.md) 机器人）都应该用自己的一份，这样可以单独撤销。

## 查看

[机器详情](machine-details.md)的「设备 Token」列出每个令牌：标签、使用端、创建时间、最近使用时间，当前设备会被标出。

## 撤销和删除

1. **先撤销**：令牌立即失效，它拥有的终端和浏览器也会关闭。
2. **再删除**记录。

撤销**当前设备**的令牌会让本设备的下一次请求返回 401，你需要重新导入有效凭证。

在后端用命令行也可以：

```bash
npm run credential -- --list-tokens
npm run credential -- --revoke <token-id>
```

命令行的撤销不需要重启后端，终端心跳会自动发现。

## 注意

- 重新生成凭证会删除旧的导出文件，但**不会撤销**已经发出的令牌。
- 不要多台设备共用一个令牌。
