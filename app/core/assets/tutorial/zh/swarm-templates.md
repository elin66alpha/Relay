## 管理

在蜂群里可以：

| 操作 | 说明 |
|---|---|
| 管理成员 | 添加、移除成员，修改昵称、提示词和设置；工作目录不能改 |
| 清空记录 | 确认后清除聊天记录和成员会话，蜂群和成员保留 |
| 删除蜂群 | 删除蜂群及其聊天记录 |

## 模板

「保存为模板」把蜂群下载成一个 JSON 文件，包含名称、成员列表和成员配置；**不包含**与机器相关的工作目录、ID 和聊天记录。

在蜂群列表里点「导入模板」，选择 JSON 文件即可用它新建蜂群。适合在不同项目或不同机器上复用同一套分工。
