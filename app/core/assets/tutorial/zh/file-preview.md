在文件系统里点一个文件就会打开只读预览。

| 类型 | 预览方式 | 限制 |
|---|---|---|
| UTF-8 文本 | 显示前 512 KiB，超出时有提示 | |
| 代码 | 支持的语言会语法高亮 | 2 万字符以内高亮，更长的显示纯文本 |
| Markdown（`.md`、`.markdown`） | 默认渲染，顶部按钮切换「查看源码」 | 不加载嵌入的图片；超过 2 万字符时直接显示源码 |
| 图片（JPG、PNG、WebP、GIF、BMP、ICO） | 可缩放查看 | 20 MiB、4000 万像素以内 |

含有 NUL 字节、不是有效 UTF-8 的二进制文件，以及损坏或过大的图片，无法预览。

预览使用下载接口，所以路径限制和下载大小上限同样适用。预览页的下载按钮保存完整文件。

聊天回复里的文件链接也会打开这个预览，见[复制、编辑与链接](messages-and-links.md)。
