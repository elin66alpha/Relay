点输入框左侧的 **+**。第一行是模型等控制项（见[模型、思考强度、权限与快速模式](agent-controls.md)），第二行是下面这些工具。

## 附加文件

可以一次选多个文件，任务运行中也能用。每个文件上传到工作区的 `.relay/uploads/`，文件名前加上本机时间 `yyyyMMdd-HHmmss-`。上传成功后，它相对于工作区的路径会追加到输入框里，你再决定何时发送。

注意：这些文件会出现在仓库的 `git status` 里，除非把 `.relay/` 加入忽略。单个文件上限默认 100 MB。

## 清空对话

清除当前会话的聊天记录并重置机器侧会话，相当于重新开始。会先弹窗确认。任务运行中不可用。

## 压缩对话

让智能体把当前对话压缩成摘要（发送 `/compact`），释放上下文空间，对话可以继续。完成后对话里会出现「对话已压缩」，[上下文用量](context-usage.md)随之更新。是否支持取决于 CLI，Claude Code 原生支持。任务运行中不可用。

## 导出 Markdown

把当前对话导出为 Markdown 文件保存到设备。导出前会对常见令牌格式做脱敏，但这不是通用的密钥扫描。
