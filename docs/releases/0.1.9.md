# Relay 0.1.9

Relay 0.1.9 adds Cursor as a fifth agent and tidies the model picker. This
release ships the Android client and the source backend setup bundle; it has no
Windows desktop client or Windows backend downloads.

## Highlights

- **Cursor joins Relay:** Cursor appears in the agent list below Codex. Once
  the host's `agent` CLI is signed in (`agent login`, or `CURSOR_API_KEY`), you
  can pick its model, reasoning effort, Fast mode and permission like Claude
  Code and Codex, with several Cursor sessions running at once. Relay's Cursor
  uses its own config directory, `server/cursor-config/`, so choices made in
  Relay never change the host's Cursor defaults. Quota Usage shows Cursor's
  included usage.
- **A tidier model list:** main models come first. Cursor models billed outside
  the plan, and older Claude Code and Codex models, move to a second page
  opened from the bottom of the screen. Swarms list main models only.
- **Current OpenCode and Hermes models:** OpenCode's list comes from the host's
  `opencode models`, including every provider configured there. Hermes gains a
  Model entry showing the model configured on the host.

Other changes:

- Claude Code no longer shows a false "log in again within a day" warning on
  Machine details.
- OpenCode, Hermes and Cursor start a new message after each tool call, as
  Claude Code and Codex do.
- Relay approves Cursor actions once only, so it no longer adds commands to the
  host user's own Cursor allowlist.
- Deleting or clearing a Cursor conversation also deletes its session record.
- The file API refuses Cursor's `auth.json`, like the Claude Code and Codex
  credential files.

See the [changelog](https://github.com/elin66alpha/Relay/blob/v0.1.9/CHANGELOG.md)
for the complete change list.
