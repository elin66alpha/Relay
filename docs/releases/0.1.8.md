# Relay 0.1.8

Relay 0.1.8 adds chat wallpapers, context usage, file attachments, and text file
previews. This release includes separate Windows desktop client and backend
downloads.

## Highlights

- **Chat wallpaper:** choose one device-local image in Settings > Wallpaper,
  adjust opacity with live preview, and save. Desktop and mobile keep the
  original image; chat chrome, messages, and Home cards share an acrylic tint.
  Display-sized decoding and a shared blurred backdrop keep scrolling smooth.
- **Context usage:** the line above the solo-chat composer shows used tokens
  and the model's context window, such as `42k / 200k`, and refreshes after
  compacting a conversation.
- **Files in your workflow:** attach files through the composer's **+** menu
  without sending automatically. Open text files in a read-only preview with
  syntax highlighting.

Other changes:

- Rename any session except Main. Copy settled messages or edit your own
  message back into the composer.
- Home has a What's new entry. Settings > About can check GitHub for a newer
  version without downloading it.
- Update CLI is available in the composer's **+** menu.
- Replies Claude starts on its own can be stopped and no longer spin forever.
- File access checks cover dot-suffixed copies of sensitive paths and symlink
  destinations. Oversized directory downloads stop scanning at the size limit.
- Backend setup verifies the native terminal dependency and supports npm 12's
  install-script policy.
- Quickly created messages keep distinct IDs, avoiding message action and
  rendering mix-ups on Windows.

See the [changelog](https://github.com/elin66alpha/Relay/blob/0.1.8/CHANGELOG.md)
for the complete change list.

## Windows backend setup

1. Extract the entire backend ZIP to a permanent, writable directory. Keep
   `server`, `backends`, and `runtime` together.
2. Install at least one supported agent CLI on this host: Claude Code, Codex,
   OpenCode, or Hermes. Complete its login or provider setup on the host.
3. Open PowerShell in the extracted directory and run:

   ```powershell
   .\setup.cmd
   .\status.cmd
   ```

4. Choose a port and network mode, then create an encrypted device credential.
   Import the generated `.relay.json` or `.relay.png` from `server/credentials`
   in the Relay client and enter the passphrase.

Node.js, npm, and backend dependencies are included. Agent CLIs and optional
`cloudflared` are installed separately. The backend archive contains no local
deployment state, credentials, or compiled Flutter client. Setup creates a
Scheduled Task that starts Relay when the current Windows user logs in.

Use these commands from the extracted directory:

```powershell
.\start.cmd
.\stop.cmd
.\status.cmd
.\credential.cmd --url https://YOUR-BACKEND
.\uninstall.cmd
```

Use HTTPS for public access. Quick Tunnel addresses can change after restart;
generate and import a new credential when the address changes. Uninstalling
stops the service and removes its login task while retaining configuration,
credentials, and history. See the bundled README for updates and log locations.
