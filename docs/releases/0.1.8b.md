# Relay 0.1.8b

Relay 0.1.8b is the latest regular release, building on 0.1.8. It makes the chat wallpaper's
acrylic look adjustable and fixes how it renders, and reorganises the backend so
more of it is covered by tests. The bundled app still reports version `0.1.8`;
the GitHub release label is `0.1.8b`.

## Highlights

- **Adjustable acrylic:** Settings > Wallpaper now has two number fields under
  the opacity slider for the acrylic blur (0-30) and tint (0-100%), shared by
  light and dark themes. The defaults are lighter than before (blur 6, tint
  55%), and the preview updates as you type.
- **Wallpaper page layout:** Replace image and Remove wallpaper sit at the top,
  and the preview stays on screen while you drag the slider or type with the
  keyboard open. The Wallpaper entry in Settings is larger and describes what
  it controls.
- **Consistent acrylic on Android:** on wallpaper pages, pulling a list past its
  end shows a glow instead of the stretch effect, which used to switch the blur
  off while you held it.

Other changes:

- If Stop fails, the chat shows why and Stop can be tried again; before, the
  failure was silent.
- Backend: upload, directory download, background-turn and scheduled-message
  code moved out of `server.js` into tested modules; the session pools share one
  cap and idle-eviction implementation; `npm --prefix server run lint` (ESLint)
  joins CI. No API changes.

## Windows backend setup

1. Extract the entire backend ZIP to a permanent, writable directory. Keep
   `server`, `backends`, and `runtime` together. The directory inside the archive
   uses the application version `0.1.8`; the download name identifies release
   `0.1.8b`.
2. Install and authenticate/configure at least one supported agent CLI on the
   host: Claude Code, Codex, OpenCode, or Hermes. Install `cloudflared` separately
   if using a Cloudflare tunnel.
3. Open PowerShell in the extracted directory and run:

   ```powershell
   .\setup.cmd
   .\status.cmd
   ```

4. Follow the port, network, and credential prompts. Import the generated
   `.relay.json` or `.relay.png` from `server/credentials` in the Relay client
   and enter its passphrase.

Node.js, npm, and backend dependencies are included. Setup creates a Scheduled
Task for the current user's login. The backend archive contains no deployment
state, credentials, or compiled Flutter client. Use HTTPS for public access.
Quick Tunnel URLs may change after restart, requiring a new credential.

Manage the backend from the extracted directory:

```powershell
.\start.cmd
.\stop.cmd
.\status.cmd
.\credential.cmd --url https://YOUR-BACKEND
.\uninstall.cmd
```

Uninstall stops Relay and removes its login task, retaining configuration,
credentials, and history. Read the bundled README for updates and log locations.
